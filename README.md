# Magnetite Drift

Full-colour Python 3 neon polarity-snatch arcade for [ElbowOS](https://x.com/ElbowOS).

Steer an iron core through a rust canyon. Flip North / South to attract opposite-pole ore, repel matching poles, and dodge slag. Combos stack when you keep catching the opposite charge.

## Play

```
pip install -r requirements.txt
python3 magnetite_drift.py --play
```

- A / D or arrows — drift
- Space / W / Up — flip polarity
- R — reset
- Esc — quit

## Record a 9:16 reel

```
python3 magnetite_drift.py --record
```

Writes `/home/workdir/artifacts/MAGNETITE_DRIFT_ElbowOS.mp4` (1080×1920, 15 s, 30 fps, H.264).
